# Security Policy

## Supported versions

This repository is a sandbox. Only the latest code on the `main` branch is
supported and receives security fixes.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, pull requests
or discussions.

Instead, use GitHub's private vulnerability reporting: open the repository's
**Security** tab and choose **Report a vulnerability**. If that option is not
available, contact the repository owner privately through GitHub and ask for a
private channel before sharing details.

Include, as far as you can:

- A description of the issue and its potential impact.
- Steps to reproduce, or a proof of concept.
- The affected version or commit, and your platform.

Remove secrets and personal data from anything you send.

## What to expect

- We aim to acknowledge your report within a few days.
- We will keep you updated while we investigate and fix the issue.
- Once a fix is available, we will coordinate disclosure with you.

## Scope

Reports about the code and documentation in this repository are in scope.
Vulnerabilities in third-party dependencies should be reported to the
respective upstream projects.
